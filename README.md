# PerfectMouse

A macOS menu bar app for separate mouse and trackpad scroll settings. It also offers a workaround for stuck Ctrl, which can make a left click open a context menu.

## Install

Requires macOS 13+ and Xcode Command Line Tools.

```bash
git clone https://github.com/eber404/PerfectMouse.git
cd PerfectMouse
./install.sh
```

Allow PerfectMouse in **System Settings → Privacy & Security → Accessibility**.

## Use

Open PerfectMouse in the menu bar. Set **Natural scrolling** for each device. If the Ctrl fix interrupts a long Ctrl hold, turn it off in the same menu.

## Uninstall

Run `./uninstall.sh` from the repo folder.
